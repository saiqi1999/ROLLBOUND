# ROLLBOUND 轮盘战记

[打开网页试玩](https://saiqi1999.github.io/ROLLBOUND/)

七店七战。招募棋子，在商店的 4×4 轮盘上触发相邻联动。战斗开始时随机抽取最多 16 名首发，其余队员按阵亡情况补位。支持手机竖屏、桌面浏览器、战斗回看和本机续局。
